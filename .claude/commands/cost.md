description: Record a new costing for a style: FOB, exchange rate, freight and duty. The earlier version is kept as superseded.
---

Confirm the figures with the operator. Run `npm run plm -- cost <style> --fob=<amount> --fx=<rate> --freight=<amount per unit> --duty=<percent> [--currency=USD] [--note=]`. Report the landed cost, the margin and the gap to target. Never invent a factory price.
