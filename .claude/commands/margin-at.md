Ask for the rate (brand currency per one unit of the FOB currency, for example 1.85 NZD per USD). Run `npm run plm -- margin-at --fx=<rate> [--currency=USD] [--season=AW27]`. Say how many styles fall under target and by how much. Nothing is saved.
