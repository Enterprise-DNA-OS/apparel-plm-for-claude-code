---
description: Ask a factory for a sample: proto, fit, sales, pre-production or top of production.
---

Confirm style, kind, size and colourway with the operator. Run `npm run plm -- request-sample <style> --kind=proto|fit|sales|pp|top --size=<size> --colourway=<colour>`. The due date defaults to the factory's sample lead time; pass `--due=YYYY-MM-DD` if the factory agreed another. Then offer /draft-sample-comments for the request note. Nothing is sent from here.
